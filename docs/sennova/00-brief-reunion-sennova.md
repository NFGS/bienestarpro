**Proyecto:** BienestarPro — sistema integral para el área de Bienestar al Aprendiz (Centro de Comercio y Turismo, Armenia - Quindío).
**Solicitante:** Nelson Fabián Gallego Sánchez — aprendiz ADSO, semillerista del grupo.
**Duración propuesta:** 45–60 minutos.
**Fecha de elaboración:** 2026-10-08.

## 1. Qué es el proyecto (30 segundos)

Plataforma web (PWA) que automatiza el proceso de refrigerios del área de Bienestar al Aprendiz, notifica por correo, WhatsApp y push a aprendices e instructores, y centraliza nuevos servicios de bienestar: fichas por jornada, contactos de emergencia, noticias y campañas, encuestas y reuniones. Diseñada multi-centro para replicarse a nivel nacional.

## 2. Estado actual (a la fecha)

- Decisiones técnicas tomadas y registradas (stack open source: PWA React + API NestJS + PostgreSQL).
- Cliente interno identificado: área de Bienestar al Aprendiz del centro.
